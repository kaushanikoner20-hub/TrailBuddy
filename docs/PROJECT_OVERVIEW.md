# Project overview

## Problem
People often want to spend time outdoors but stay tied to their screens. Planning an outing usually means more scrolling: maps, listicles, apps.

## Target user
Anyone who wants a simple, low-pressure reason to go outside for 15 minutes to a couple of hours, whatever their fitness level.

## Solution
TrailBuddy asks three questions (activity, time, difficulty) and uses a local AI model to write a short outdoor adventure made of a few simple activities. You read it once, then go outside.

## Philosophy
*Let AI prepare the experience, then let the user put the phone away and experience the real world.*

The AI is a preparation tool, not a companion to stare at. It runs locally so the project does not depend on an external AI provider.

## Why it exists
TrailBuddy is a small open-source project for the Hacktoberfest 2026 "Touch Grass" challenge. Stage 1 (current) delivers the foundation: a working React → Express → Ollama → Gemma 3 pipeline. Later stages are planned but not built.
